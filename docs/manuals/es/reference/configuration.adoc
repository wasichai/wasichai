[[sys-configuration]]
== Configuración

La aplicación se configura con propiedades de Spring Boot (`application.yml`, variables de entorno, argumentos).
Ningún módulo trae un `application.yml`: los valores por defecto están en las clases `@ConfigurationProperties` y en
`WasichaiEnvironmentPostProcessor`, que aporta, con la prioridad más baja, la conexión a base de datos desde las
variables `WASICHAI_DB_*`. Spring admite la forma de variable de entorno de cualquier propiedad:
`wasichai.gis.geoserver.enabled` → `WASICHAI_GIS_GEOSERVER_ENABLED`.

=== Variables de entorno

[cols="2,1,3",options="header"]
|===
|Variable |Por defecto |Uso
|`WASICHAI_DB_HOST` |`localhost` |Servidor PostgreSQL.
|`WASICHAI_DB_PORT` |`5432` |Puerto.
|`WASICHAI_DB_NAME` |`wasichai` |Base de datos.
|`WASICHAI_DB_USERNAME` |`wasichai` |Usuario.
|`WASICHAI_DB_PASSWORD` |`wasichai` |Contraseña. *Secreto.*
|`WASICHAI_JWT_SECRET` |_(ninguno)_ |Clave HMAC de los JWT, al menos 32 bytes. Sin ella la aplicación no arranca.
*Secreto.*
|`ANTHROPIC_API_KEY` |_(vacía)_ |Clave del asistente (módulo agent). Sin ella el asistente queda desactivado.
*Secreto.*
|`PORT` |`8090` |Puerto HTTP de `full-sample` (definido en su `application.yml`).
|===

Los secretos se proporcionan desde el entorno de ejecución (gestor de secretos, variables protegidas del CI); nunca
se escriben en `application.yml` ni en el repositorio. Los valores por defecto de la base de datos son de desarrollo.

=== Ejemplo de configuración de producción

[source,yaml]
----
# application-prod.yml de una aplicación propia. Los secretos llegan por variables de entorno.
server:
  port: 8080
wasichai:
  security:
    jwt:
      secret: ${WASICHAI_JWT_SECRET}
      ttl: 4h
      revocation: true
    login:
      enabled: true
    password:
      min-length: 12
      require-digit: true
      not-equal-email: true
  web:
    cors-allowed-origin-patterns: [ "https://licencias.example.org" ]
  gis:
    geoserver:
      url: https://geoserver.internal.example.org/geoserver
      username: ${GEOSERVER_USER}
      password: ${GEOSERVER_PASSWORD}
----
