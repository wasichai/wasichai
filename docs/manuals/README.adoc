= Wasichai manuals

User, administrator and system manuals of Wasichai, in Spanish (`es/`) and English (`en/`), written in AsciiDoc and
built to an HTML site and six PDF books (ADR-070). The Markdown reference in `docs/` (API, modules, ADRs, history)
stays canonical for what it covers; the manuals link to it.

== Layout

[cols="1,3"]
|===
|`attributes.adoc` |Product version, edition date, shared links. Change them on a release.
|`es/`, `en/` |`index.adoc` and `{user,admin,system}-manual.adoc`, their chapters in `user/`, `admin/`, `system/`,
`reference/`, `operations/`. Same files and anchors in both languages.
|`theme/` |`pdf/wasichai-theme.yml`, `html/wasichai-docs.css`, IBM Plex fonts (SIL OFL, `fonts/OFL-IBM-Plex.txt`).
|`assets/` |`branding/` (the docs emblem), `diagrams/` (Mermaid sources in `src/<lang>/`, PNGs generated),
`screenshots/<lang>/` (generated by Playwright).
|`database/` |The demo dataset (`fixtures/`), its SQL copy (`backups/`), manifest (`manifests/`) and `verify.sql`;
see `database/README.adoc`.
|`scripts/` |`build.sh`, `validate.mjs`, `render-diagrams.mjs`, `screenshots.mjs`, `seed-demo.mjs`,
`export-demo-db.sh`, `restore-demo-db.sh`.
|`output/` |Generated `html/` and `pdf/`. Not committed.
|===

== Tools

Ruby 3.3 with Bundler (gems pinned in `Gemfile.lock`) and Node 26 with Yarn 1 (Playwright and Mermaid, pinned in
`package.json`).

[source,bash]
----
# from docs/manuals/
bundle config set --local path .bundle/gems && bundle install
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 yarn install      # then: npx playwright install chromium, or set CHROMIUM_PATH
----

== Commands

From the repository root:

[source,bash]
----
yarn docs:validate      # references, images, es/en parity, line length, no secrets
yarn docs:build         # PDFs, then the HTML site (with the PDFs in it): docs/manuals/output/
yarn docs:html          # or one format
yarn docs:pdf
yarn docs:diagrams      # assets/diagrams/*.png from assets/diagrams/src/<lang>/*.mmd
yarn docs:clean         # removes docs/manuals/output/
----

The screenshots and the demo database need full-sample running (server on 8090, web on 4173 or 5173):

[source,bash]
----
export WASICHAI_DEMO_PASSWORD='Demo-2026!'           # local demo only
yarn docs:db:seed                                     # load the dataset through the REST API (idempotent)
WASICHAI_DB_NAME=wasichai_demo yarn docs:db:export    # plain SQL + manifest
WASICHAI_DB_NAME=wasichai_demo_restore yarn docs:db:restore   # restore + verify
WEB_URL=http://localhost:4173 yarn docs:screenshots   # 40 screenshots per language
----

The system manual's chapters _Mantener estos manuales_ / _Maintaining these manuals_ and _Base de datos de
demostración_ / _Demo database_ describe the whole procedure.
